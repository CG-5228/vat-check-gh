# Source decisions and assumptions

Verified 23 October 2026. This app gives a practical explanation and estimates, not an official determination. The table includes verified source decisions and app conventions used where the sources leave a gap. Code that implements a calculation or screening assumption carries a `// ASSUMPTION:` comment.

## Unresolved official guidance

The FAQ does not establish a refund timetable, prove that any individual bank is already integrated, or settle all business-to-business, withholding-credit and reconciliation questions. KPMG's observation section also describes those uncertainties. This consumer app does not handle VAT filing, input-credit claims or statutory exemption rulings. It does not promise that a payment provider will treat every transaction correctly.
